# السنبلة للتنمية — نظام الإدارة

نظام لإدارة الجمعيات الشريكة والمشاريع والتبرعات والدفعات وكفالة الأيتام والتقارير، بالعربية وباتجاه RTL، والعملة الريال القطري.

## الوحدات

| الوحدة | ما تفعله |
|---|---|
| لوحة المؤشرات | الإجماليات، والهدف السنوي ونسبة تحققه، والتوزيع حسب الدولة والقطاع والسنة والجمعية، والدفعات المستحقة، وآخر التبرعات |
| المشاريع | إضافة وتعديل وحذف، مع الحالة ومراحل التنفيذ والدفعات والتبرعات والتقارير لكل مشروع، وتصفية وتصدير Excel |
| الجمعيات | بيانات الجهات الشريكة والشعار، وملخص مشاريعها |
| التبرعات | سجل التبرعات وربطها بمشروع أو جمعية، وتصفية وتصدير |
| الدفعات | الدفعات المجدولة للجهات المنفذة، وتنبيه المتأخر، وتسجيل الصرف |
| الأيتام والكافلون | سجل الأيتام والكافل والدفعات الشهرية |
| التقارير | تقارير مصورة لكل مشروع، وطباعتها أو حفظها PDF |
| المستخدمون | مدير النظام، وموظف، وحساب جمعية يرى بيانات جمعيته فقط |
| الإعدادات وسجل النشاط | الهدف السنوي، ونصوص الصفحة العامة، وسجل كل عملية |

يبدأ النظام فارغاً، وفيه فقط حساب مدير النظام.

## النشر على Netlify

1. في Netlify: **Add new project ← Import an existing project ← GitHub ← sunbula-paltform**. الإعدادات تُقرأ من `netlify.toml`.
2. قبل أول نشر، من **Data & Storage ← Database** اختر **Create a database**. أو ضع `DATABASE_URL` لقاعدة PostgreSQL خاصة بك.
3. في **Project configuration ← Environment variables** أضف: `AUTH_SECRET` و `ADMIN_EMAIL` و `ADMIN_PASSWORD`.
4. **Deploys ← Trigger deploy**. الصور تُحفظ تلقائياً في Netlify Blobs.

## التشغيل بـ Docker

```bash
cp .env.example .env
# عدّل في .env: AUTH_SECRET (نص عشوائي طويل) و ADMIN_EMAIL و ADMIN_PASSWORD و DB_PASSWORD
docker compose up -d --build
```

ثم افتح `http://SERVER:3000/login` وادخل ببريد المدير وكلمة مروره. شغّله خلف HTTPS في الإنتاج، لأن ملف تعريف الدخول لا يُرسل إلا عبر اتصال آمن.

## التشغيل بدون Docker

المتطلبات: Node.js 20 أو أحدث، وPostgreSQL 14 أو أحدث.

```bash
npm install
cp .env.example .env        # ضع رابط قاعدة البيانات وبيانات المدير
npx prisma migrate deploy
npm run db:seed             # ينشئ حساب المدير فقط
npm run build && npm start  # على المنفذ 3000
```

للتطوير: `npm run dev`.
